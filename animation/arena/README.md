# 数学思维训练场｜全新原创版

- **学习入口：** https://zhanglingshare.github.io/grade7-math-visualized/animation/arena/
- **代码位置：** `animation/arena/`
- **状态：** 已实现一版可玩的四区域核心体验，尚未完成真实学生效果验证与移动端真机验收。
- **范围：** 小学思维桥梁（7场）、七年级上册第一章（6场）、第二章（9场）、第三章（6场）。
- **编写方式：** 课程、题目、提示、迁移题和动态图形为新写内容；**不使用** `cn-math-taxonomy` 的说明文字、题库或先修关系作为新版教学内核。

## 课程边界与课本

以用户提供的人教版《义务教育教科书·数学·七年级上册》为教学对齐依据：

- **第一章** 1.1 正数和负数；1.2 有理数及其大小比较
- **第二章** 2.1 有理数的加法与减法；2.2 有理数的乘法与除法；2.3 有理数的乘方
- **第三章** 3.1 列代数式表示数量关系；3.2 代数式的值

**特别区分：** 此版本是28场精选核心探索和28道独立迁移题，**不是**三章的全部课后题、完整测评体系，也未替代第一章252题、第二章156题等已存在的历史题库。旧题库暂作备查，不强迫孩子刷完，必须先核题后才考虑迁入新版。

## 为什么这样重构

孩子已经在球场上表现出主动观察高手、选择更强的对手、输后找原因与调整打法的习惯。设计不是“把数学变成体育”，而是迁移其能够自主学习的机制：

1. **自己出手：** 预测并选择，不惩罚猜错；
2. **动手实验：** 改变数量／方向／结构，观察数学对象的响应；
3. **观察高手：** 提示可选，先尝试再看另一种解释；
4. **换招再战：** 换一题检测是否理解数学结构，而不是照抄演示；
5. **自己复盘：** 记录“我理解了／还想试／还没懂”，不做排名；
6. **爸爸陪练：** 可自行出题考爸爸，构建探索关系，而非让家长充当裁判。

页面是四个导航区域：小学桥梁、第一章、第二章、第三章。**任何实验都可独立进入和继续**，不会要求先完成小学六年全部内容。

## 设计与操作标准

- 使用原先孩子喜欢的米色网格纸＋深色黑板舞台、橙色强调；桌面端／手机端均布局自适应。
- 使用16类数学 SVG 场景。至少包含：数轴、分数、数位／分组、天平、面积、立体积木（几何实验附加视角）、机器、配比、符号、分类、乘法规律、幂、运算次序、代数变量、费用模型和双机器对照。
- 在小屏幕上允许点击和滑杆调整；部分场景支持触摸数学对象本身，例如分数条点击取份、分组点击重组、天平点击同时移去；不应把所有拖动都称为“自由对象拼装”。
- 不加后台上传、广告、倒计时、排行榜或强制登录。数据仅存设备当前浏览器 LocalStorage `math-arena-original-v1`。
- 允许家长说明数学原理，但先听孩子讲自己的想法；不将罚错、恐吓或羞辱作为任何教学策略。
- 初步表现只用作下一题的教学判断，不断言智商、注意力障碍或掌握程度。
