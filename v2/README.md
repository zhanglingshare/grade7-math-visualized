# 七年级数学 V.2 · 把数学看见

新版地址：https://zhanglingshare.github.io/grade7-math-visualized/v2/

按用户提供的人教版七年级数学上册前三章（原书1—87页）重建：第一章有理数，第二章有理数的运算，第三章代数式。

- 19个互动实验：第一章5个、第二章8个、第三章6个。
- 81道选择题、50道屏幕书写题，附解释与参考答案；第一章包含39道选择题和22道屏幕书写题。
- 10次周六两小时课表，包括休息；进度可以延长。
- 动画可播放、暂停、继续；手机与电脑均可操作。
- 每节包括动手实验、猜一猜、讲一讲、屏幕作答。
- 浏览器本机保存体验、作答与家长观察记录。
- 第一章已按教材六个知识点扩充为14个互动玩法，详见 [第一章说明](CHAPTER-ONE.md)。每次按需选择，不要求一堂课完成。

V.2位于独立v2/目录，原版仍位于仓库根目录。无需安装依赖，也无需登录。

## 本地运行

将本目录用任意静态文件服务器打开。也可直接打开index.html。

检查计算与课程数据：

    node check-math.cjs

教材页码及内容对应见TEXTBOOK-COVERAGE.md，家长完整课表见parent-guide.md，验证记录见VALIDATION.md。原教材PDF未包含在项目中。

## 手机／平板电子书写（2026-11-07）

所有原“纸笔”开放题均可直接在设备上使用触控笔或手指书写，并支持撤销、清空、输入答案与核对参考。原有选择题继续点选。每道题的笔迹与输入内容存储在当前设备的浏览器 localStorage，不会自动跨设备同步，也不会上传服务器。手写过程目前不做自动数学识别和评分；可对照题目参考自行核验。原有实验与题库不删除。
