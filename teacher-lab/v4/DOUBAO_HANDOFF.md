# 林老师 V4 — 豆包 / 火山方舟实时教学接入任务书

> 版本：Prototype 0.1 ｜ 现有工作台：\`teacher-lab/v4/index.html\` ｜ 负责人分工：GPT 负责前端 HTML/可视化/交互原型；豆包负责模型服务、语音识别、服务端、网络接口、联调。不得删除现有六类期中题与原有教学流程。
>
> 核心目标：培养 **读题 → 制定策略 → 独立尝试 → 自我核验 → 复盘 → 陌生题迁移**，而非堆积答题次数。林老师是唯一面向孩子的主持人；五个观察员是后台岗位，不要五个机器人同时和孩子说话。

## 1. 对接前必须理解现状

当前 V4 已实现：四张不同表情/手势人物画面切换；浏览器中文语音；6 类期中错题、18 步挑战；数学动画；本地学习行为事件存储（\`LIN_OBSERVER_V4.events()\`）；五岗位规则观察工作台；事件 JSON 导出；计划时长、读题目标、策略选择、答题结果、主动核验与复盘。

当前 V4 **尚未实现**：真实多模型协同、实时自然语言理解、真实语音识别、模型后端、服务器数据同步、跨设备学习档案、延迟复测服务。不可宣传为已实现。

## 2. 逻辑岗位与最小数据

| 岗位 | 输入 | 输出 | 禁止事项 |
|---|---|---|---|
| 思维观察员 observe | 已表述的目标、孩子选择的解题方法、作答轨迹 | \`evidence_ids[]\` 和可检验的下一问题 | 不得推断注意力缺陷、智力、性格 |
| 教学策略师 strategy | 错误答案的数学结构、提示层级、换方法记录 | 一步提示／策略转换建议 | 不直接交最终答案（除非孩子主动请求完整讲解） |
| 动画实验师 animation | 题型、关键数学关系、学生请求 | JSON 动画参数和时间点 | 不擅自发明题目数值、修改标准答案 |
| 习惯教练 habit | 自选时长、是否先读题、选方法、核验、复盘 | 微小可执行习惯建议 | 不把停留时间当专注度 |
| 过关考官 exam | 无提示陌生变式、答题记录、隔天复测 | 掌握程度证据（不是人格评分） | 不因一次答对宣称永久掌握 |

建议**先用一个调度器 + 规则引擎 + 1 个实时大模型**。不同岗位在逻辑上分工，不必每个事件并发请求五个大模型。只有解释开放性思路、孩子口语表达、复杂错因等环节调用方舟大模型。

## 3. 行为事件格式（现有前端）

\`\`\`json
{
  "schema": "lin.behavior.v1",
  "id": "sxyz-42",
  "session": "sxyz",
  "task": "q23:1",
  "type": "method_selected",
  "ts": "2026-11-24T03:00:00.000Z",
  "elapsed_ms": 28000,
  "payload": {"method": "画图"},
  "source": "real"
}
\`\`\`

已生成事件类型：\`task_open\`、\`goal_stated\`、\`method_selected\`、\`method_changed\`、\`answer_attempt\`、\`self_check\`、\`cause_selected\`、\`reflection\`、\`plan_set\`、\`hint\`、\`demo_started\`、\`demo_manual_start\`、\`demo_pause\`、\`demo_replay\`、\`demo_scrub\`、\`student_idea\`、\`student_retry\`、\`harder_requested\`、\`quiet_requested\`。

**必须基于用户明确同意才上传。** 默认仍然只保存于浏览器。不得采集持续摄像头、麦克风、屏幕录像、精确地理位置或设备指纹。学生昵称仅用于界面称呼，服务端尽量使用随机匿名 ID，不传全名。

## 4. 推荐服务端接口契约

所有接口通过你自己的服务端代理访问方舟。HTML 中绝对不能出现火山方舟、豆包或其他服务商的 API Key / Token。

### \`POST /api/v1/learning/observe\`

输入：\`{ session_id, task_id, events: [...] }\`

输出：
\`\`\`json
{
  "role": "strategy",
  "evidence_ids": ["sxyz-40","sxyz-41"],
  "confidence": "low|medium|high",
  "observation": "同一类题出现两次未通过提交，未观察到主动换方法",
  "suggested_action": "invite_strategy_change",
  "requires_teacher_review": false,
  "uncertainty": "尚未采集孩子的口头解释，无法确认其真实思路"
}
\`\`\`

仅允许 \`suggested_action\` 为 \`wait\`、\`ask_goal\`、\`ask_reason\`、\`invite_strategy_change\`、\`play_demo\`、\`offer_hint\`、\`invite_self_check\`、\`invite_reflection\`、\`assign_transfer\`。没有可靠证据时用 \`wait\`。

### \`POST /api/v1/mentor/respond\`

输入：\`{ student_utterance, task_id, question, official_solution, evidence_ids, hint_level, context }\`

输出：
\`\`\`json
{
  "mentor_text": "峰玮，你说相遇后可能还会再次相距5格。我们把两个点继续往前推，看看你的猜想。",
  "emotion": "listen",
  "stage_action": {"type":"scrub_demo","time":2.0},
  "follow_up": "你认为相遇前后可能有几个时间？",
  "evidence_ids":["sxyz-41"],
  "show_final_answer":false
}
\`\`\`

\`emotion\` 仅允许 \`listen\`、\`explain\`、\`think\`、\`celebrate\`。动画动作仅允许前端白名单：\`play_demo\`、\`pause_demo\`、\`scrub_demo\`、\`none\`。**让模型建议动作，由前端状态机检查后执行**，模型不得直接执行任意 JavaScript。

### \`GET /api/v1/mentor/stream\`（可选 SSE） 

事件：\`mentor.text\`、\`mentor.expression\`、\`demo.action\`、\`observer.handoff\`、\`task.completed\`。若需要低延迟语音双向交互，由豆包实现受控 WebSocket/实时服务端，先有显式麦克风开关和授权，关闭后不录制/不上传。必须有文本、按钮方式替代语音。

## 5. 学习交互要求

1. 新题开始，老师先问目标或要求选方法，不马上给答案。
2. 孩子主动解释思路时先倾听，然后对照数学条件，提出**一个**针对性追问。
3. 答错后区分具体计算错误、漏条件、分类讨论不全；证据不足时应说“不确定”，请孩子表达步骤。
4. 同一题两次未通过，可建议换方法或启动演示；不应因 30 秒不操作就认定走神。
5. 孩子说“先让我想”，暂停语音播报并允许安静思考。孩子说“我不懂”，给分级提示，不立即剧透。
6. 答对要确认方法与依据；无提示完成新变式才记为**初步迁移证据**。隔天使用新的题目做延迟复测。
7. 孩子自行制定计划和反思，不能强制按秒行动或把时间当惩罚。

## 6. 安全、成本与数据治理

- 默认离线可运行。AI 接口宕机时退回 V4 本地规则逻辑。
- 真实未成年人数据：最小化、显式授权、导出/删除/撤回；服务端只接受白名单事件字段，限制内容长度；生产部署前核查适用的儿童隐私和数据合规要求。
- 方舟密钥仅存环境变量；服务端鉴权、配额、速率限制、审计与异常熔断。公开免费项目必须防止 API 额度被滥用。
- 优先用前端确定性判题；只有**需要解释和理解孩子语言**时请求模型，必要时缓存高频题的动画讲解。
- 观察员判断必须返回 \`evidence_ids\`、\`uncertainty\`，不得声称 AI 能直接观察孩子脑内想法。
- 父母/教师查看后台必须在正式公开版接入明确权限管理；当前后台开放**仅用于开发试点**。
- 不要暴露完整标准答案给孩子的模型提示窗口，除非到了适当教学阶段。
- 任何自动提示要能让孩子关闭，避免打断深入思考。

## 7. 交付与测试（豆包需要负责）

- 一套可运行服务端 + 环境变量示例（不含真实密钥）。
- 保留原 HTML 内容，不破坏原来数学动画、四表情人物、六类题目及本地记录。
- 事件上报前需用户显式同意；断网、限流、超额、安全拦截都有明确降级。
- 在观察后台显示模型响应、基于哪几条事件推断、何时调用、Token 成本、是否被规则拒绝。
- E2E 测试：未选方法点击提交；连续两次答错；学生选“先让我想”；拖动数轴；提交新变式；切换题目；撤回授权；模型超时；语音不可用；刷新/清空数据。
- 不以孩子答对率单独证明学习能力提升。至少设计一轮 4 周小样本：基线任务、训练过程、无提示陌生题、延迟复测、孩子主观体验，记录样本与限制。

**最重要的产品验收：孩子关闭林老师后，能否更自觉地先读题、选择方法、自己检查、主动复盘。**
