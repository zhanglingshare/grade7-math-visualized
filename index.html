第1章 · 有理数

1.1 正数和负数

负数不是"减出来的"，它是专门用来表示相反意义的量：零上还是零下、赚钱还是欠钱、海平面以上还是以下。

0 是分界线，比 0 大是正数，比 0 小是负数
拖一拖温度计
同一个温度计，一个 0，两边世界
拖动滑块，看温度在「零上 / 零下」之间切换，水银跟着走
20
零上 20 ℃正数：可以直接写 20
这一节学到了
  • 正数：比 0 大，如 3、+8、1/2（可以省掉 + 号）
  • 负数：比 0 小，如 −3、−8，前面一定有 − 号
  • 0 既不是正数也不是负数，它是分界线
小思考

如果「收入 50 元」记作 +50，那「支出 20 元」该记作什么？海平面以下 30 米呢？

想一想：相反意义的量，符号正好反过来。

1.2 数轴：有理数排队

把所有的数排成一队，队伍的名字叫数轴。0 站在中间，正数在右，负数在左。

数轴上越靠右，数字越大
点一点 · 拖一拖
在数轴上放一个小球，读出它代表几
点任意位置放球，或用按钮一格一格走
小球在 0
从左到右 = 从小到大−5 在 −3 的左边，所以 −5 < −3
这一节学到了
  • 数轴三要素：原点 0、正方向（向右）、单位长度
  • 任何一个有理数，都能在数轴上找到它的位置
  • 比较大小：右边的数永远大于左边的数
小思考

−3 和 −1 哪个大？用数轴上的位置解释一下为什么。

离 0 越近的负数，反而越大。

1.3 相反数 · 绝对值

相反数是关于 0 照镜子；绝对值是到 0 的距离——距离怎么可能为负？

|a| 永远 ≥ 0
拖一拖 a
看 a 和 −a 在 0 两边照镜子，量一量到 0 的距离
3
a = 3，−a = −3关于 0 对称，方向相反
|a| = 到 0 的距离|3| = 3，|−3| 也是 3
这一节学到了
  • a 的相反数是 −a，它们到 0 的距离相等，方向相反；0 的相反数是 0
  • |a| 是 a 到 0 的距离：正数不变，负数变正数，0 还是 0
  • 所以绝对值永远不可能是负数
小思考

|−7| 等于几？|x| = 5，x 可能是几？（提示：有两个答案）

距离 0 有 5 个格子，左边一个，右边一个。
第1章 · 有理数

1.4 加减法：数轴上走路

加减法不用背口诀，记住两句话：加 = 向右跳，减 = 向左跳。跳到哪，答案就是哪。

减去一个数 = 加上它的相反数
选算式 · 一步步看
小球在数轴上跳格子，每一步都看得见
先猜一猜：这道题的答案是多少？
(−2)+5站在 −2，向右跳 5 格
想一想 · 追问三步（答完再看下一问）
第 1 问：小球向右跳，是在加还是在减？向左跳呢？
第 2 问：5 − (−2) 为什么等于 5 + 2？在数轴上想想：减负就是掉头向右。
第 3 问：换个数试试：(−3) + 4 = ？先在心里猜，再去数轴上验证。
这一节学到了
  • 加法：向右跳；减法：向左跳
  • 减去一个数 = 加上它的相反数：5 − (−2) = 5 + 2 = 7
  • 同号相加取同号，异号相加看"谁离 0 更远"——数轴上跳一跳全明白
小思考

用"跳格子"的方法算一算：(−6) + 10 和 (−3) − 4，答案是几？

(−6)+10：从 −6 向右跳 10 格；(−3)−4：从 −3 向左跳 4 格。

1.5 乘除法：正负颜色

符号规则一句话：同色得正、异色得负。先看颜色定符号，再算数字大小。

(−) × (−) = (+)，(−) × (+) = (−)
拖一拖两个数
绿色是正数、红色是负数，看颜色怎么决定结果
3
−2
3 × (−2) = −6  ·  3 ÷ (−2) = −1.5
奇负偶正几个负数相乘：数一数负号的个数，奇数个是负，偶数个是正
这一节学到了
  • 正 × 正 = 正；负 × 负 = 正；正 × 负 = 负
  • 除法也一样：同号得正、异号得负，再把绝对值相除
  • 0 不能做除数
小思考

(−2) × 3 × (−4) 的符号是正是负？数一数一共几个负号。

两个负号 = 偶数个 = 正。结果等于 +24。
第1章 · 有理数

1.6 乘方：叠方块

aⁿ 是 n 个 a 相乘，不是 a×n！指数是指挥官：它说"一共乘几次"。

2³ = 2×2×2 = 8，不是 2×3
拖一拖 · 数一数
每个方块都是一次相乘，数一数一共多少个
2
3
2³ = 2 × 2 × 2 = 8
注意！2³ ≠ 2×32³ 是三个 2 相乘，2×3 才是两个 2 相加再乘
易错 · −3² 和 (−3)²

−3² = −(3×3) = −9（先算乘方，负号留在外面）

(−3)² = (−3)×(−3) = +9（括号让负号也一起乘了）

同一个数字，括号在不在，结果差一倍方向！
小思考

(−2)³ 等于几？（提示：3 个 −2 相乘，奇数个负号）

10² 和 2¹⁰ 哪个大？

(−2)³ = −8；2¹⁰ = 1024 比 10² = 100 大得多。
第2章 · 整式的加减

2.1 字母与单项式：神秘的盒子

字母 x 不是一个怪物，它只是一个盒子——里面装着我们还不知道的数。装几次，就是几次方。

单项式 = 数字（系数） × 字母（字母的几次方）
选一选 · 拆一拆
把单项式拆成「系数 × 字母盒子」
x 是盒子，装着还不知道的数3x = 3 × x，前面的 3 叫系数
这一节学到了
  • 用字母表示数：a+b、S=ab、周长 C=2(a+b)
  • 单项式：数与字母的乘积，如 3x、−2x²、xy；数字部分叫系数
  • 多项式：几个单项式的和，如 x+4、2x²−3x+1；每个单项式叫一项
小思考

3x 的系数是几？次数是几？5x² 的次数呢？（提示：次数是字母乘了几次）

3x：系数 3，次数 1；5x²：系数 5，次数 2。
第2章 · 整式的加减

2.2 同类项合并：积木归类

合并同类项就像收拾玩具：只有一模一样的积木才能叠在一起。x 的积木和数字积木，永远不能加在一起。

同类项 = 字母相同、字母次数也相同
一步步看
3x + 2 − 5x + 4 是怎么变成 −2x + 6 的
把玩具摆开先看清楚有哪些积木
3x + 2 − 5x + 4 = −2x + 6
这一节学到了
  • 同类项：字母一样、次数也一样（比如 3x 和 −5x）
  • 合并：系数相加减，字母和次数原样不动
  • 去括号：括号前是 − 号，里面每一项都要变号
小思考

4a − 7 + a + 2 等于什么？先找同类项（4a 和 a），再合并数字。

4a + a = 5a，−7 + 2 = −5，答案是 5a − 5。
第3章 · 一元一次方程

3.1 天平与等式性质

方程就是一个天平：左右一样重，等式才成立。解方程的每一步，都只是"两边做同样的事"。

等式性质：两边同加、同减、同乘、同除（0 除外），等式仍然成立
点一点 · 看天平
2x = 4：左边两个 x 方块，右边四个数字方块，刚好平衡
天平水平 · 等式成立左边 2x + 0，右边 4 + 0
这一节学到了
  • 等式 = 天平平衡：两边一样重，用等号连起来
  • 性质 1：两边同时加或减同一个数，等式仍成立
  • 性质 2：两边同时乘或除以同一个数（不能除以 0），等式仍成立
小思考

如果 x + 3 = 8，你准备两边同时做什么，才能让 x 单独站在左边？

两边同时减去 3：x + 3 − 3 = 8 − 3，得到 x = 5。
第3章 · 一元一次方程

3.2 解方程：天平分步

解 2x + 3 = 7，就是一步步"让 x 单独站出来"：先去数字，再平分。

目标：让 x 孤零零站在天平的一边
一步一步 · 播放
2x + 3 = 7 的完整天平求解
先猜一猜：x 是多少？
摆好天平左盘：2 个 x + 3 个数字；右盘：7 个数字
2x + 3 = 7
想一想 · 追问三步（答完再看下一问）
第 1 问：第一步，天平两边同时做了什么？（提示：拿掉了什么）
第 2 问：为什么两边同时 −3 之后，天平还是平的？
第 3 问：换一道：3x + 1 = 10，先猜 x，再按天平思路解一解。
这一节学到了
  • 第 1 步：两边同时 −3，去掉多出来的数字 → 2x = 4
  • 第 2 步：两边同时 ÷2，让 x 单独站一边 → x = 2
  • 检验：把 x = 2 代回去：2×2 + 3 = 7
小思考

用天平思路算：3x + 1 = 10。第一步做什么？第二步做什么？

先两边 −1 → 3x = 9；再两边 ÷3 → x = 3。

3.3 移项：为什么变号

课本说"移项要变号"，那是一条硬规定吗？不是。它只是"两边同时减去同一项"的结果——看一遍动画就永远忘不了。

移项 = 两边同时减掉它 → 变号是自然结果
一步步看
3x + 4 = 2x + 6：右边的 2x 是怎么跑到左边的
x 项 数字项 正在做的事
先看题目两边都有 x，先想办法让 x 只出现在一边
这一节学到了
  • 3x + 4 = 2x + 6，两边同时 −2x：右边 2x 消失，左边多出 −2x
  • "移到另一边" = "两边同时减掉它"，所以符号会变：+2x 变 −2x
  • 不是规定，是"两边做同样的事"推出来的结果
小思考

5x − 2 = 3x + 8：要把右边的 3x 移过来，两边应该同时做什么？移过来后左边变成什么？

两边同时 −3x：左边 5x − 3x = 2x，等式变成 2x − 2 = 8。
第3章 · 一元一次方程

3.4 应用题：先找等量

应用题不怕字多，秘诀只有一步：把题目的"相等关系"翻译成等式。天平就是题目本身。

设未知数 → 找等量关系 → 列方程 → 解方程
选一道题 · 分步解
买笔问题
小明买 3 支笔和 1 个 2 元的本子，一共 11 元。每支笔多少钱？
等量关系：3 支笔的钱 + 本子的钱 = 总钱数设每支笔 x 元
3x + 2 = 11
这一节学到了
  • 设未知数：把要求的量用 x 表示（每支笔 x 元）
  • 找等量：3 支笔 + 1 个本子 = 一共花的钱 → 3x + 2 = 11
  • 解出来 x = 3，再回题目检查一遍，答：每支笔 3 元
小思考

爸爸今年 x 岁，小明今年 12 岁，爸爸的年龄 = 小明年龄的 3 倍。列方程算一算爸爸多大。

等量：x = 3 × 12，所以爸爸 36 岁。
第4章 · 几何图形初步

4.1 直线 · 射线 · 线段

区别只有两个字：端点。线段两个端点、射线一个端点、直线没有端点。

线段能度量，直线射线都不能
点一点 · 切换
看三种线，端点在哪里
端点数量：0 · 1 · 2记不住？数端点就行
这一节学到了
  • 直线：无端点，无限延伸，记作直线 AB
  • 射线：1 个端点，向一端无限延伸，记作射线 AB（A 是端点）
  • 线段：2 个端点，长度固定可度量，记作线段 AB
小思考

手电筒发出的光，像直线、射线还是线段？为什么？（提示：光源是端点吗）

像射线：从手电筒出发向远处无限延伸，只有一个端点。

4.2 角：转出来的

角不是"画"出来的，是一条射线绕着端点旋转出来的。转得多大，角就多大。

∠AOB = 旋转的角度
拖一拖 · 转一转
抓住紫色边，绕 O 点转，看角怎么变大变小
60
锐角 · 小于 90°转得越多，角越大
这一节学到了
  • 角：一条射线绕端点旋转而成，记作 ∠AOB
  • 锐角 < 90° · 直角 = 90° · 钝角 90°~180° · 平角 = 180°
  • 角平分线：把一个角分成两个相等的角
小思考

一个角 80°，它的角平分线把它分成两个几度的角？

80 ÷ 2 = 40°，两个角都是 40°。
第4章 · 几何图形初步

4.3 余角 · 补角

两个角拼在一起 = 90°，叫互余；拼在一起 = 180°，叫互补。像拼图一样。

同角的余角相等 · 同角的补角相等
拖一拖 · 拼一拼
把两个角拼起来，看它们凑成多少度
35
35° + 55° = 90°它们互余
这一节学到了
  • 互余：两个角加起来 = 90°，α 的余角 = 90° − α
  • 互补：两个角加起来 = 180°，α 的补角 = 180° − α
  • 同角（或等角）的余角相等、补角相等
小思考

70° 的余角是几度？补角是几度？

余角 90−70 = 20°；补角 180−70 = 110°。

4.4 正方体展开图

正方体被"展开铺平"就是展开图。展开图一共有 11 种，记住关键：6 个面、排列要能围起来。

找对面：展开图上相隔一块的两面，折起来正好相对
选一个 · 试试折
这些图形能不能折成正方体？动手试试
拖动正方体 · 转一转看对面
选择一张展开图同色的两个面，折起来后正好相对
这一节学到了
  • 正方体有 6 个面，展开图必须有 6 个相连的正方形
  • 常见 11 种展开图：一四一、二三一、二二二、三三 等
  • 判断能不能折成正方体：6 块、相连、没有"田字形"堵死
小思考

展开图里，标相同颜色的两个面折起来会怎样？（提示：相对）

相隔一块的两个面，折起来正好面对面。
第4章 · 几何图形初步

4.5 三视图：立体看平面

同一个立体，从正面、左面、上面看，看到的"影子"可能完全不同。考试常考：给你立体，画三视图。

正面看 → 主视图 · 左面看 → 左视图 · 上面看 → 俯视图
换一个方向看
这个 L 形立体，三个方向看到的格子各不同
正面看：像一截楼梯只画你"看得见"的小方格
这一节学到了
  • 主视图：从正前方看；左视图：从正左方看；俯视图：从正上方看
  • 画三视图时，被挡住的方块不画
  • 同一立体，三个视图经常长得不一样
小思考

一个正方体，它的主视图、左视图、俯视图分别是什么形状？

三个方向看都是正方形——所以正方体才叫"正"方体。
