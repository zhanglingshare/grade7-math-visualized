# 七年级数学 V.2 · 把数学看见

新版地址：https://zhanglingshare.github.io/grade7-math-visualized/v2/

按用户提供的人教版七年级数学上册前三章（原书1—87页）重建：第一章有理数，第二章有理数的运算，第三章代数式。

- 19个互动实验：第一章5个、第二章8个、第三章6个。
- 57道选择题、38道纸笔题，附解释与参考答案。
- 10次周六两小时课表，包括休息；进度可以延长。
- 动画可播放、暂停、继续；手机与电脑均可操作。
- 每节包括动手实验、猜一猜、讲一讲、纸上试试。
- 浏览器本机保存体验、作答与家长观察记录。

V.2位于独立v2/目录，原版仍位于仓库根目录。无需安装依赖，也无需登录。

## 本地运行

将本目录用任意静态文件服务器打开。也可直接打开index.html。

检查计算与课程数据：

    node check-math.cjs

教材页码及内容对应见TEXTBOOK-COVERAGE.md，家长完整课表见parent-guide.md，验证记录见VALIDATION.md。原教材PDF未包含在项目中。
