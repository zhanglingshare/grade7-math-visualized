## 第五章覆盖

依据用户上传的人教版七年级上册教材：

- **5.1 方程：** 从算式到方程、未知数、方程的解、等式性质。
- **5.2 解一元一次方程：** 逆向操作、移项、合并同类项、去括号、去分母和多步变形；并纳入教材“探究与发现：无限循环小数化分数”。
- **5.3 实际问题与一元一次方程：** 单价与数量关系、行程追及、生产配套、工作效率等量关系；训练“实际问题—数学问题—实际问题”的完整闭环。

第五章11场每场包含先判断、互动实验、迁移题和自主复盘，首批共22道核心判断／迁移题。另新增独立500题电子题库：5.1为100题、5.2为200题、5.3为200题；50类问题结构，每题2至7个步骤，包含选择、等式输入和数值输入。题库按教材例题与习题的结构编排：造纸产量、灌溉比例、螺栓螺母配套、分段工作量、布料采购、长方形周长、树苗余缺、两位数、登山追及、相向行驶、顺逆风、列车过隧道、销售盈亏、球赛积分、日历、空调综合费用、复印收费和机场线月票；代数部分覆盖合并同类项、移项、去括号、去分母、多步变形和无限循环小数化分数。

## 质量门

新增文件：
- `chapter5-extension.js`：独立增加第五章课程数据，不改写前四章原始课程数据。
- `chapter5-visuals.js`：仅接管第五章11种专用场景，其余章节继续使用原可视化渲染器。
- `chapter5-bank.js`：生成500道分层练习，50类问题结构，100/200/200章节配比。
- `chapter5-practice.html`、`chapter5-practice.js`、`chapter5-practice.css`：独立电子练习页，支持逐步解锁、等式输入、分数输入、提示、错题复练和本地进度。
- `tests/chapter5-bank-smoke.cjs`：检查500题结构和等式计算。
- `tests/chapter5-smoke.cjs`：检查课程数量、题目结构、关键方程结果和页面脚本接入。
- 原有 `tests/smoke.cjs`：更新新版训练场总课程数和第五章入口预期。

运行：
```sh
node animation/arena/tests/smoke.cjs
node animation/arena/tests/chapter5-smoke.cjs
node animation/arena/tests/chapter5-bank-smoke.cjs
```

## 设计原则

延续米色网格纸、深色黑板舞台、橙色强调；孩子先预测，再操作数学对象，最后换题迁移并用自己的话复盘。第五章重点把“移项”还原成等式两边同时做相同运算，不把口诀当成原理。手机和平板沿用现有响应式布局、触控滑杆和本地浏览器进度。
